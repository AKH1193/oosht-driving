# Real vehicle sounds (optional)

Wise City synthesises engine and horn sounds by default. To use real recordings instead,
add audio files to this folder and push. The next APK build includes them automatically.

File names (any of .ogg, .mp3, .m4a, .wav):

- `engine_<vehicle>.ogg`: a steady engine loop recorded at about 3,000 rpm. The game speeds
  it up and slows it down with the revs.
- `horn_<vehicle>.ogg`: a horn sound; it loops while you hold HORN.
- Or by category, used when there is no file for the exact vehicle:
  `engine_two.ogg`, `engine_three.ogg`, `engine_car.ogg`, `horn_two.ogg`, `horn_three.ogg`, `horn_car.ogg`.

Vehicle names: saathi, sakhi, bijli, pratham, rocket, maharaja, nandi, kesari, garuda, agni,
auto, hatch, sedan, suv.

Use recordings you made yourself or ones with a licence that allows reuse (for example CC0).
